# EDUVIA — التثبيت على الهاتف والنشر · دليل مختصر

المنصّة **PWA قابل للتثبيت**: بعد فتحها على الهاتف يمكن «تثبيتها» فتعمل من الشاشة
الرئيسية، وتُفتح بلا إنترنت (مع مزامنة الكتابات عند عودة الشبكة).

## 1) التجربة على الحاسوب
```bash
node serve.js
```
ثم افتح <http://localhost:8080/>. زر **«⬇️ تثبيت التطبيق على الهاتف»** يظهر أسفل
الشاشة متى كان المتصفّح يدعم التثبيت. التثبيت الحقيقي يُجرَّب على الهاتف عبر HTTPS.

## 2) النشر الرسميّ — GitHub Pages

| الموقع | الرابط |
|---|---|
| منصّة المدرسة | <https://brandheroman4.github.io/smart-school-demo/> |
| بوّابة الأولياء (صفحة تحويل) | <https://brandheroman4.github.io/eduvia-parent-app/> |

- المستودعان **عامّان**، والنشر من فرع `main` تلقائيًّا (GitHub Actions).
- تحديث الموقع = `git push`؛ لا رصيد استضافة ولا اعتماد على Netlify.
- ملفّات النشر تقتصر على ما يحتاجه الزائر: `index.html` · `manifest.json` ·
  `sw.js` · `icons/` · `brand.html` · `parent-app.html`. أمّا `sql/` و`tests/`
  و`tools/` والوثائق فتبقى في المستودع ولا تُنشر.
- `roster.csv` وقوائم التلاميذ (`students*.csv`) **مستثناة من Git أصلًا**، فلا
  تصل إلى GitHub ولا إلى الموقع المنشور.
- Netlify يبقى نسخة احتياطية عند الحاجة، لكنه ليس العنوان الرسميّ.

## 3) تثبيت تطبيق الوليّ على الهاتف
أرسل للأولياء رابط **البوّابة**، يدخلون برقم الهاتف والرمز السرّي. بعد فتح المنصّة:
- **Android / Chrome:** زر «تثبيت التطبيق على الهاتف» أسفل الشاشة، أو قائمة
  المتصفّح ← «تثبيت التطبيق».
- **iPhone / Safari:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية» (لا يظهر زر
  تثبيت تلقائي في iOS).

## 4) للنشر على Google Play (لاحقًا)
حوّل الـPWA إلى حزمة APK عبر **PWABuilder.com** — تحتاج حساب مطوّر Google Play
(25$ لمرة واحدة).

## ملفات الـPWA
- `manifest.json` — هوية التطبيق والأيقونات
- `sw.js` — التخزين المؤقت والعمل دون إنترنت
- `icons/` — أيقونات 192/512/maskable + apple-touch
- `serve.js` — خادم محلي للتجربة فقط (لا يُنشر)
